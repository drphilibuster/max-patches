# max-patches

Max and Max for Live devices.

| Device | What it is |
|---|---|
| [Pad Toggle](PadToggle/) | Max for Live MIDI effect: every pad hit toggles a Drum Rack loop on or off, with Note Offs ignored. Made for e-drums and pad controllers. Adds mono groups, launch quantise, Retrig/Gate/Thru pads, a hit guard and a custom canvas UI (loop rings, quantise countdowns, a hits timeline, a full-screen stage view). Live 12.2+. |

Each device folder has its own README (install, use) and TESTING (what was
verified, and how). Devices are generated from code rather than hand-patched,
so their wiring and layout are reviewable in git.
